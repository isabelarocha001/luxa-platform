# Luxa Platform

Adult creator platform for the **European market** — web-first (Next.js + TypeScript + React).

UX inspired by OnlyFans / Fansly profile flows. Not a clone of their code or brand.

## Stack
- Next.js 15 (App Router)
- TypeScript + React 19
- Tailwind CSS
- Stripe (card-only, EU)

## Local
```bash
npm install
cp .env.example .env.local
npm run dev
```
